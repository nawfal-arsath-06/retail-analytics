The Retail Analytics Dashboard is an interactive business intelligence project developed using Microsoft Power BI and PostgreSQL. It analyses retail sales data to provide a clear view of revenue, profitability, order activity, product categories, and regional performance. The dashboard helps business users explore performance trends and compare results using interactive filters. Data is sourced from PostgreSQL and prepared and modelled in Power BI using Power Query and DAX.

## Technology Stack

**Data Source:** PostgreSQL
**Data Visualization:** Microsoft Power BI
**Data Transformation:** Power Query
**Data Modelling and Calculations:** DAX
## KPI Cards

The dashboard includes the following KPI cards:

**Total Revenue:** Sum of sales generated.
**Total Profit:** Total profit earned.
**Total Units Sold:** Total quantity of products sold.
**Total Orders:** Distinct count of orders.
**Total Customers:** Distinct count of customers.
## Visualisations

The Sales Overview page includes:

**Monthly Revenue Trend:** Shows how revenue changes over time.
**Revenue by Product Category:** Compares revenue generated by each product category.
**Profit by Region:** Compares profitability across regions.
**Profit Distribution by Category:** Shows how total profit is distributed among product categories.
## Interactive Filters

The dashboard includes slicers for:

Order Date
Product Category
Customer Segment
Region
These filters allow users to interactively narrow the data and explore performance across different time periods, product categories, customer segments, and regions.

## Data Model

The project uses four PostgreSQL tables:

**Orders:** Order dates, order IDs, customer and product references, quantities, sales, costs, discounts, and profit.
**Customers:** Customer details, segments, locations, and region references.
**Products:** Product names, categories, subcategories, and unit costs.
**Regions:** Region names and country information
